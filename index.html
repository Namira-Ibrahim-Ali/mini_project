Enforcing Cloud Firestore & Identity Platform

This portal communicates with Firebase via modern modular drivers. The active engine executes strict server-grade RBAC rules locally and can link to any Google Firebase project instantly.

// firestore.rules active matrix:
/events/{id} - Public read; Faculty/Admin write (Society scoped)
/calendarRequests/{id} - Admin & owning Faculty read; Faculty create; Admin update/delete
/users/{id} - Authenticated read; Admin write (Zero-knowledge passwords)
Note: To connect your official live Google Firebase project, provide your credentials in firebase-config.js and run firebase deploy --only firestore:rules.
